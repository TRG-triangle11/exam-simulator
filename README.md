# 考试模拟器 · 模拟考场

一个运行在浏览器里的高考考场氛围模拟器，供个人刷题时使用：营造真实的考试环境、提前适应考场节奏，帮助你专注作答。

## 功能特性

- 模拟高考考场流程：考前准备 → 开考 → 作答 → 15 分钟提醒 → 收卷
- 教室考场背景，营造沉浸氛围（课桌椅、黑板、黄昏光线）
- 右上角常显当前北京时间
- 大号白色倒计时，一目了然

### 设置页

- 科目选择：语文、数学、英语、物理、化学、生物、政治、历史、地理，或自选科目
- 考试时长与科目默认联动，选择科目后自动套用推荐时长，可再手动调整：
  - 语文 → 2 小时 30 分
  - 数学、英语 → 2 小时
  - 物理、化学、生物、政治、历史、地理 → 1 小时 15 分
  - 自选科目 → 2 小时
- 自定义时长：按小时 + 分钟精确设置
- 考试名称可修改，默认显示“普通高等学校招生全国统一考试”，显示在考场黑板上
- 考前准备 5 分钟（发放试卷、答题卡、填写信息），可勾选：
  - 勾选：先进入 5 分钟准备，铃声响起后自动开考
  - 不勾选：3 秒倒计时后直接开考
- 所有设置会被记住，下次打开自动恢复

### 考前准备（5 分钟）

- 独立倒计时“准备倒计时”，与考试倒计时分开显示
- 准备期间可随时“放弃本次考试”，确认后返回设置页
- 准备结束自动响起开考铃声，并播报“考试开始，请开始作答”

### 考试中

- 黑板上显示考试名称与放大的科目名
- 剩余时间不足 15 分钟时：铃声 + 语音提醒“还剩最后十五分钟，请合理安排时间”，顶部出现红色横幅
- 考试结束：响铃 + 语音播报“考试结束”，显示科目、考试时长、实际作答时间、交卷时间
- 可“提前交卷”，需弹窗确认

### 全屏沉浸

- 右下角有全屏按钮，平时隐藏，鼠标移到右下角时浮现
- 全屏后按钮变为“退出全屏”
- 全屏状态下鼠标静止约 2 秒自动隐藏，移动鼠标即恢复显示

### 声音

- 右上角静音按钮可随时开关所有声音
- 铃声为合成电铃声，人声为考场广播风格语音
- 浏览器要求：首次点击“开始考试”后声音才会播放

## 使用方法

1. 用 Chrome 等现代浏览器打开 `index.html`
2. 选择科目与时长（或自定义），填写考试名称
3. 按需勾选“考前准备 5 分钟”
4. 点击“开始考试”，进入考前准备或直接开考
5. 全屏后安心作答，倒计时会自动完成整个流程

## 目录结构

```
exam-simulator/
├── index.html          # 主程序（单文件，含样式与逻辑）
├── README.md
└── assets/
    ├── classroom.jpg   # 考场教室背景图
    ├── voice_start_s.wav   # 开考语音
    ├── voice_15min_s.wav   # 15 分钟提醒语音
    └── voice_end_s.wav     # 考试结束语音
```

注意：`index.html` 依赖同目录下的 `assets` 文件夹，移动或转发时请连同文件夹一起拷贝。

## 技术说明

- 单文件自包含：HTML、CSS、JavaScript 全部内联在 `index.html` 中，无需安装、无网络依赖
- 铃声用 Web Audio API 实时合成，语音用内嵌音频文件播放
- 显示时间固定为北京时间（Asia/Shanghai）
- 界面字体：标题与科目名使用华文中宋（衬线），正文使用 HarmonyOS Sans SC 等标准无衬线字体
- 偏好设置（科目、时长、考试名称、勾选项）保存在浏览器 localStorage
- 触屏设备上自动隐藏右下角全屏按钮，桌面端体验最佳
